# Artificial Intelligence Lab 1

## Lab 1: Introduction to AI & Paradigms

### Objective
To understand Artificial Intelligence and compare
Symbolic AI with Probabilistic AI.

## Files Included

1. lab1_compare.py
2. lab1_rules.py
3. Lab1_Report.docx
4. outputs/compare_output.txt
5. outputs/rules_output.txt

## Requirements
- Python 3.8 or above
- VS Code

## How to Run

Run the following commands:
python lab1_compare.py
python lab1_rules.py

## Description

lab1_compare.py:
Compares rule-based and probability-based decisions.

lab1_rules.py:
Implements scholarship screening using four conditions.

## Conclusion

This lab demonstrates the difference between
rule-based and probability-based AI systems.
